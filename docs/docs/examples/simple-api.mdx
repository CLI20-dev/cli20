# Simple API

This is the first example to open when you want the default cli20 flow. It
shows the smallest useful cli20 program: one flag, one optional named argument,
and one required positional input.

## What This Example Shows

This example declares a CLI as ordinary typed fields, mixes a flag with an
optional named value and a required positional, and lets cli20 handle standard
help and error flow. On success, `verbose` becomes a `bool`, `output` holds an
optional path-like string, and `input` holds the required file name.

# Callback Entry Point

Open this when parsing should populate application state for some other entry
point, service object, or orchestration function.

This page is the bridge between cli20 and a larger application architecture.
The parser gathers state first, and then your real program entry point runs with
that prepared state.

## What This Example Shows

This example updates application state incrementally as each argument is parsed
and then hands the finished state to the real entry point. It keeps CLI wiring
at the edge, supports repeated `--include` options without swallowing
positionals, and leaves the final state in `verbose`, `jobs`, `includes`, and
`inputs`.

<ExampleCommands
  items={[

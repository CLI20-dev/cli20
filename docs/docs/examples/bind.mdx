# Bind

Use this when your program already has destination variables and you do not want
to read values back out of `Args`.

This page is for the case where cli20 is only one part of a larger program and
the final state already lives in ordinary local variables or objects.

## What This Example Shows

This example binds parsed values directly into existing variables, so the real
state lives outside `Args` from the start. It is useful when the surrounding
program already owns `port`, `output`, and `ratio`, and on success those values
are written straight into their target `int`, `std::string`, and `double`
variables.

## Try It

<ExamplePlayground name="bind" defaultArgs="--port 9000 --output release.bin --ratio 1.5" />

Things to try:

- **Happy path** — `--port 9000 --output release.bin --ratio 1.5`
- **Defaults** — run with no arguments to see the pre-bound default values
- **Help** — `--help`
- **Bad ratio** — `--port 80 --ratio abc` to see conversion fail

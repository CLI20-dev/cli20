Detailed Description

template<class T>
struct cli::ParseResult< T >

The result returned by Parser::parse() and the free cli::parse() function.

On success, value holds the fully populated argument specification struct and error is in the default (no-error) state. On failure, error describes what went wrong and value is in a partially-initialised (unusable) state.

Typical usage:

auto result = cli::parse<MyArgs>(argc, argv);
if (!result) {
std::cerr << result.error.message() << '\n';
return 1;
}
// use result.value …

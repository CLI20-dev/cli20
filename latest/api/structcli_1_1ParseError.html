Detailed Description

Carries all context about a single parse/validation failure.

A ParseError is embedded in both ParseResult<T> and ActionResult<T>. When code == ErrorCode::unknown_error the struct represents the absence of an error (i.e. success).

Typical usage after parsing:

auto result = cli::parse<MyArgs>(argc, argv);
if (!result) {
auto& e = result.error;
auto& out = e.use_stdout() ? std::cout : std::cerr;
out << e.message() << '\n';
std::exit(e.exit_code());
}

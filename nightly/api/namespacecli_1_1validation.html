Detailed Description

Actions that validate a typed value after conversion.

Each action in this namespace passes its input through unchanged on success or returns ErrorCode::validation_failed / ErrorCode::invalid_choice on failure. They are placed after a conversion action and before a pack action:

constexpr auto my_action = cli::conversion::integer<int>
| cli::validation::range<1, 100>
| cli::pack::set_once;

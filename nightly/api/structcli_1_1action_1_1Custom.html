Detailed Description

template<auto Fn>
struct cli::action::Custom< Fn >

Wraps a user-defined callable as a non-terminal action pipeline step.

Fn must be invocable as:

ActionResult<U> Fn(ActionCtx<void> ctx, ActionResult<T> input);
cli::ActionCtx
Context passed to each action function during pipeline execution.

cli::ActionResult
The result type produced and consumed at each step of an action pipeline.

for each input type T it supports. The returned ActionResult<U> becomes the input to the next action in the pipeline.

This is the escape hatch for conversions or transformations that do not fit the built-in conversion or validation actions. Unlike pack::callback, Custom does not terminate the pipeline and does not store a value; its storage_type is always void.

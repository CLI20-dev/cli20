Detailed Description

template<class T>
struct cli::pack::StoreInto< T >

Writes the value directly into an external variable via a T* pointer.

Storage type: T*. The pointer must be non-null at the time of parsing; returns ErrorCode::validation_failed with a descriptive message if the pointer is null. Used as the action for BoundOption.

Template Parameters
TThe type of the external variable.

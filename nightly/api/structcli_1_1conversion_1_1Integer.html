Detailed Description

template<std::integral T>
struct cli::conversion::Integer< T >

Converts a string token to an integral type T using std::from_chars.

Returns ErrorCode::invalid_value for non-numeric or partially-consumed input, and ErrorCode::out_of_range when the value overflows T.

Template Parameters
TThe target integral type (e.g. int, unsigned long).

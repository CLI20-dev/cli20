Detailed Description

template<std::size_t N>
struct cli::StringLiteral< N >

Compile-time string type usable as a non-type template parameter.

C++20 allows class-type NTTPs provided the type satisfies structural requirements. StringLiteral<N> wraps a null-terminated character array so that string names such as "verbose" can appear directly in template argument lists:

cli::Flag<"verbose", 'v'> verbose;

Detailed Description

template<auto Pred>
struct cli::validation::Predicate< Pred >

Validates a value using a user-supplied compile-time predicate.

Pred must be a constexpr callable of the form (const T&) -> bool. Returns ErrorCode::validation_failed when Pred returns false.

Template Parameters

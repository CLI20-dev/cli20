Detailed Description

Partial specialisation of ActionCtx used for intermediate pipeline steps.

Conversion and validation actions do not have access to the final storage; they receive ActionCtx<void> which carries only the positional counters. This specialisation also provides a converting constructor from ActionCtx<T> so that the parser can downcast when invoking non-terminal actions.

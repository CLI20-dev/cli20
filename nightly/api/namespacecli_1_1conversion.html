Detailed Description

Actions that convert a raw std::string_view token to a typed value.

Each action in this namespace transforms the pipeline value from a string representation into a specific C++ type. They are typically placed first in an action pipeline, before validation and pack actions.

Example:

constexpr auto my_action = cli::conversion::integer<int> |
cli::pack::set_once;

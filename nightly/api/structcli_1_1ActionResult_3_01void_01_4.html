Detailed Description

Specialisation of ActionResult for terminal (pack) actions that produce no value.

Pack actions such as SetTrue or Push write their result directly into the argument storage referenced by ActionCtx::arg; they do not pass a value downstream, so ActionResult<void> carries only an error, success, or ignore state.

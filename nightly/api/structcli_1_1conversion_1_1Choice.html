Detailed Description

template<class T, auto Mapper>
struct cli::conversion::Choice< T, Mapper >

Converts a string token to type T via a user-supplied mapper function.

Mapper must be a constexpr callable of the form (std::string_view) -> std::optional<T>. Returns ErrorCode::invalid_choice when the mapper returns std::nullopt.

Template Parameters
TThe target value type.
MapperA constexpr callable mapping strings to std::optional<T>.

Detailed Description

template<class T>
struct cli::ArgParameter< T >

Parameter bag used when constructing ArgImpl or PositionalImpl with named fields.

Allows brace-initialisation with named members, e.g.:

cli::Option<int, "count"> count{cli::ArgParameter<int>{
.help = "Number of repetitions",
.presence = cli::required,
.default_value = 1,
}};

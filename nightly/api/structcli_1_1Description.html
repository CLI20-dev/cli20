Detailed Description

A DescriptionTag field that carries the top-level CLI description.

Add an instance of Description as a member of your argument specification struct to provide a paragraph that appears in the help output between the usage line and the options/positionals sections:

struct MyArgs {
cli::Description description{"Does something useful."};
cli::Flag<"verbose"> verbose;
};

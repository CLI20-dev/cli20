Detailed Description

template<class T>
struct cli::ActionResult< T >

The result type produced and consumed at each step of an action pipeline.

An ActionResult<T> is either a success carrying a value of type T, or a failure carrying a ParseError. The operator bool(), has_value(), and has_error() methods make it easy to check the state inline.

Factory methods:

  • ActionResult<T>::ok(value) — create a success result.
  • ActionResult<T>::fail(error) — create a failure result.

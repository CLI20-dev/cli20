Detailed Description

Post-parse constraint helpers.

Each function checks a relationship between options and returns a ConstraintResult. Combine results with && or ||:

auto constraints() -> cli::ConstraintResult {
return cli::constraint::one_of(foo, bar)
&& cli::constraint::requires_if(output, format);
}

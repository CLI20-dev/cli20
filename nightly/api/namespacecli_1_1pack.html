Detailed Description

Terminal actions that write the converted (and validated) value into argument storage.

Pack actions are always the last step in an action pipeline. They define the storage_type alias that determines the type of the field's .value() member.

Example:

constexpr auto my_action = cli::conversion::integer<int> | cli::pack::push;

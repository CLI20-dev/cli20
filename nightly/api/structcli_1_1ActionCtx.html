Detailed Description

template<class T = void>
struct cli::ActionCtx< T >

Context passed to each action function during pipeline execution.

Provides access to the current argv position, how many times the parent option has been seen, how many times the action has been invoked so far, and a reference to the argument's storage value.

Template Parameters
TThe storage type of the argument; void for intermediate (non-terminal) actions.
